# Аудиокниги

Лёгкое веб-приложение для телефона: загружаешь книгу (PDF, EPUB, TXT) на русском
или румынском — оно озвучивает её нейронными голосами Microsoft Edge (бесплатно)
и сохраняет аудио на телефоне, чтобы слушать без интернета и с выключенным экраном.

## Как устроено

- `index.html`, `app.js` — библиотека и плеер (позиция, скорость, экран блокировки).
- `extract.js` — текст из PDF (pdf.js) / EPUB (JSZip) / TXT, нарезка на куски ≤1500 символов.
- `store.js` — IndexedDB: книги и готовое MP3 по кускам.
- `sw.js` — кэш оболочки, чтобы приложение открывалось офлайн.
- `api/tts.py` — функция Vercel: `POST /api/tts {text, voice}` → MP3 через `edge-tts`.

## Выкладка

```
vercel deploy --prod
```

## Тест

```
sh tests/run.sh
```

Браузерный тест (Playwright) на сгенерированных PDF и EPUB; голоса Microsoft
подменены заглушкой. Нужны python3 с reportlab, ffmpeg и Chromium.

## Ограничения

- `edge-tts` — неофициальный доступ к голосам Edge, Microsoft может его закрыть.
  Запасной вариант — Piper (см. `docs/QUEUE.md`).
- Сканы PDF (картинки страниц) без распознавания текста не читаются.
