# Открытые пункты

1. Владелец: проект Google Cloud + ключ TTS + бюджетное оповещение, ключ в Vercel.
2. Выложить на Vercel и проверить настоящую озвучку ru/ro на телефоне
   (в т.ч. что голоса ru-RU-Chirp3-HD существуют).
3. Проверить фоновое воспроизведение с выключенным экраном на iPhone и Android.
4. Сверх 1 млн символов в месяц Chirp дорог (≈ $15 за книгу) — при большом
   объёме: запасной голос WaveNet (≈ $2 за книгу) или Silero для русского.
5. Возможно: распознавание сканов PDF (OCR), оглавление по главам.
