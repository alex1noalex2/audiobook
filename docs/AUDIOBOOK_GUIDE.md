# Озвучка книг: руководство для ИИ и для владельца

Этот файл передают любому ИИ-помощнику, чтобы тот продолжил работу, не зная прежней переписки. Репозиторий:
https://github.com/alex1noalex2/audiobook (ветка `main`, открытый). Журнал решений — `docs/CHANGELOG.md`, очередь
идей — `docs/QUEUE.md`.

## 0. Что сказать ИИ (вставьте в начало чата)

> Ты помогаешь озвучивать книги (EPUB, PDF, TXT) моим голосом. Прочитай
> https://raw.githubusercontent.com/alex1noalex2/audiobook/main/docs/AUDIOBOOK_GUIDE.md и действуй по нему. Отвечай по-русски,
> коротко: сделано / изменено / не решено. Новую функцию сначала опиши мне и жди согласия. Не утверждай, что звучит хорошо,
> пока я не послушал: слух только у меня. Код выкладывай в репозиторий и проверяй тестами `python3 -m unittest discover -s tests`.

## 1. Цель и вкус владельца

- Книги читает один голос (клон голоса владельца), качество «как у диктора»: правильные ударения, без съеденных окончаний,
  естественные паузы, вопрос слышен как вопрос, имена и места из Библии понятны.
- Бесплатно или почти бесплатно; озвучка запускается без кода: Mac (страница в браузере) или Google Colab.
- Заголовки, оглавление и примечания читает тот же голос, примечания и заголовки — с лёгким эффектом телефона (0,4).
- Результат: MP3 по частям, итоговый MP3 и таймкоды глав для Телеграма.
- Первая книга: «Два Вавилона» (Хислоп, EPUB, 14 ч 31 мин, 2664 куска после удаления дубля раздела).

## 2. Как устроено (карта файлов `local/`)

| Файл | Роль |
|---|---|
| `book2audio.py` | Общая библиотека: чтение EPUB/PDF/TXT, `book_chunks` (куски ≤400 знаков; длинные предложения режутся пополам по запятой; вопрос всегда последний в куске; дубль раздела убирается), `speak` (текст для модели), `tidy`, `phone_effect`, `join` (части MP3 по 100 кусков), `concat_parts`, `guard` (отпечаток запуска) |
| `ru_text.py` | Нормализация: числа, годы, сокращения, римские цифры, латиница, ссылки на стихи («Откровение, глава семнадцатая, стих пятый»); `plus_stress` — ударения «+» |
| `book2audio_f5.py` | **Главный полный прогон** F5-TTS на видеокарте (Colab/Kaggle) и на Mac. Режимы: обычный, `--questions N` (проба), `--assemble`, `--redo-weak` |
| `app.py`, `app.html` | Страница в браузере для Mac: бросить книгу, выбрать голос, три действия (озвучить / пересобрать / переозвучить слабые) или подготовить Colab |
| `setup_mac.sh`, `Озвучить книгу.command` | Установка и запуск на Mac двойным щелчком |
| `make_ref.py` | Из длинной записи голоса нарезает образцы 8–11 с с расшифровкой (GigaAM) |
| `verify.py` | Проверка речью: GigaAM/Whisper, `similarity` (последнее слово строже), `segments` |
| `intonation.py` | Подъём тона в конце вопроса (Praat, `praat-parselmouth`) |
| `timecodes.py` | Таймкоды глав по длине частей MP3 |
| `bench.py` | Стенд проб на отрывках книги: варианты `plus plusref phone0.4 steps32 speed1.0 check3 …`, пишет mp3 + оценка.md |
| `book2audio_cuda.py`, `colab.ipynb` | Старый прогон на OmniVoice (не использовать, оставлен для истории) |

## 3. Выбранная конфигурация и почему

Выбрана по слуху владельца на пробах `bench.py`:

- **Модель:** Misha24-10/F5-TTS_RUSSIAN (`F5TTS_v1_Base_v2/model_last_inference.safetensors`), 32 шага, скорость 1.0.
  Лицензия CC-BY-NC: только некоммерческое использование. Для коммерческого — ESpeech-TTS-1_RL-V2 (Apache-2.0,
  `--f5-repo ESpeech/ESpeech-TTS-1_RL-V2 --f5-model espeech_tts_rlv2.pt --f5-vocab vocab.txt`), но владелец счёл его менее
  выразительным и чуть менее чётким.
- **Ударения:** Silero Stress расставляет «+» в тексте **и в тексте образца** (`plus`, `plusref`). «+» убирается в словах с
  одной гласной и перед «ё». Кроме Silero, ничего не использовалось; имена и редкие слова ловятся плохо — для них
  `fixes.txt` рядом с книгой («слово = как записать, с +»).
- **Голос:** `ref_01.wav` + `ref_01.txt` — 8–11 с из записи владельца, с ~1 с тишины в конце (требование F5). Синтетический
  образец (OmniVoice) давал невнятность и «роботность»; живая запись решила. Образец с вопросом (`ref_05`) для вопросов
  **не использовать**: поднимает тон всего голоса.
- **Вопросы:** модель вопрос не интонирует. Решение: вопрос заканчивает кусок, тон последних 0,5 с поднимается на 4
  полутона (`--q-boost`, Praat). Подобрано владельцем на пробе.
- **Проверка речью:** GigaAM-v3 (`gigaam-v3-e2e-rnnt`, onnx-asr) сравнивает расшифровку с текстом, куски ниже порога 0,9
  пересчитываются (по умолчанию 2 попытки). Ударения она не ловит.
- **Пауза после запятой:** длинные предложения режутся пополам по запятой (не по размеру), конец куска без знака дополняется
  запятой. Хвост из одного слова на конце куска ломал интонацию.
- **Скорость:** на Colab T4 около реального времени (15–20 с на кусок, книга 14 ч ≈ 12–14 ч работы). Mac M1: скорость F5
  **не измерена**.

Что пробовали и отвергли: OmniVoice (игнорирует знак «+», КАПС для ударений портит речь, плохо на длинных текстах),
синтетические образцы, ASR-проверку как замену слуху, образец с вопросом как образец голоса, склейку/«расширение пауз»
(`gaps`) как основной приём (оставлена опция).

## 4. Как запускать

### На Mac (без кода)
1. Один раз: `git clone https://github.com/alex1noalex2/audiobook ~/audiobook-code`; нужны Homebrew, `ffmpeg`, Python 3.12.
2. Положить голос в `~/Audiobook/voices/Имя.wav` + `Имя.txt` (текст записи, точный).
3. Двойной щелчок `~/audiobook-code/local/Озвучить книгу.command` → страница в браузере → бросить файл → голос → кнопка.
   Результат: `~/Audiobook/books/<книга>/`. Скорость на M1 неизвестна; для длинных книг режим «В Google Colab».

### Порядок в папке Audiobook (Google Диск и Mac одинаково)

```
Audiobook/
  voices/Саша.wav + Саша.txt        голос (образец + точный текст записи); остальное в voices/образцы/, voices/исходные/
  books/<книга>/<книга>.epub        книга, рядом <книга>.drop.txt (что не читать) и <книга>.fixes.txt (произношение)
  books/<книга>/audio/              куски 00000.wav…, report.json (не трогать, по ним идёт продолжение)
  books/<книга>/<книга>.mp3, _частьNN.mp3, _таймкоды.txt, _проверить.txt
  _удалить/                         проба и старое; стирает владелец (потом очистить Корзину)
```
Новая книга = новая папка `books/<имя>/`; одну папку на две книги не делать. Навести порядок в старой куче:
`python3 local/organize_drive.py /content/drive/MyDrive/Audiobook` (план) → `… --apply --fixes-for babylon` (выполнить).

### В Google Colab (T4 GPU) — одна ячейка для любой книги
Меняется только `NAME` (имя папки книги):

```
from google.colab import drive
drive.mount('/content/drive')
FOLDER = "/content/drive/MyDrive/Audiobook"
NAME = "babylon"
BOOK = f"{FOLDER}/books/{NAME}"
!rm -rf /content/audiobook && git clone -q https://github.com/alex1noalex2/audiobook /content/audiobook
!pip install -q f5-tts silero-stress onnxruntime "onnx-asr[hub]" num2words praat-parselmouth pypdf pymorphy3 pymorphy3-dicts-ru
!python /content/audiobook/local/book2audio_f5.py {BOOK}/{NAME}.epub --ref {FOLDER}/voices/Саша.wav --out {BOOK}/audio
print("ГОТОВО")
```

- Продолжение после обрыва: **запустить ту же ячейку** (готовые куски `NNNNN.wav` не пересчитываются).
- Дополнительные ключи (в конец команды): `--questions 8` (проба вопросов, ничего не меняет), `--assemble` (пересобрать части,
  книгу и таймкоды без модели, достаточно CPU), `--redo-weak` (переозвучить слабые куски и ссылки на стихи с хвостом и 4
  попытками), `--tries 1` (без проверки речи, быстрее), `--q-boost 6` (сильнее подъём), `--speed`, `--steps`.
- Итог в `books/<книга>/`: `<книга>.mp3`, `<книга>_таймкоды.txt`, `<книга>_проверить.txt` (худшие куски по времени),
  `<книга>_частьNN.mp3`; куски и `report.json` — в `books/<книга>/audio`.
- Нарезать образцы из длинной записи: `python3 local/make_ref.py запись.mp3 --out voices/образцы` (в Colab нужны
  `silero-stress onnxruntime "onnx-asr[hub]" num2words`).

### Бесплатные лимиты и обходы
Colab free: сессия ~2–5,5 ч, потом лимит T4 восстанавливается 12–24 ч. Обход: второй Google-аккаунт (папку `Audiobook`
дать редактором, у второго «Добавить ярлык на Диск», та же ячейка), платные 100 единиц ($9,99), Kaggle (~30 ч в неделю,
отдельный блокнот не сделан). Две сессии одновременно на одну папку **не запускать**.

### Сравнение других движков (если F5 не подходит книге)
`local/engines_test.py` озвучивает один и тот же отрывок вашим голосом движками chatterbox (MIT, выразительность `--exaggeration`),
voxcpm2 (Apache-2.0), qwen3 (Apache-2.0) и печатает скорость и (с `--check`) сходство с текстом. В Colab (Python 3.13) им нужен
свой Python: `pip install uv`, `uv venv --python 3.12 /content/venv` (для chatterbox 3.11), `uv pip install --python /content/venv/bin/python <пакет> numpy soundfile pymorphy3 pymorphy3-dicts-ru num2words pypdf`.
Пакеты: `chatterbox-tts`, `voxcpm`, `qwen-tts`. Знака «+» у них нет. Не проверено на слух: русский у всех трёх заявлен в документации, не нами.

## 5. Как улучшать качество (цикл)

1. Слух владельца — единственный критерий. Он присылает заметки «время — слово — что слышно».
2. Проба: `bench.py` на отрывках (`--at 0.25 0.5 0.75`, 200 слов) с вариантами `plus+plusref+phone0.4+steps32+speed1.0`
   и одним изменением за раз; файлы в `Audiobook/bench_*`.
3. Правка текста — через `fixes.txt` (слово = замена с «+») или `ru_text.py` (+ тест в `tests/test_ru_text.py`).
4. Проверка: `python3 -m unittest discover -s tests`; в сводке отчёта владельцу — что проверено, что **нет**.
5. Полный прогон после согласия владельца; затем `--redo-weak` для слабых мест.

## 6. Ловушки, на которые уже наступали

- `ModuleNotFoundError: onnxruntime` — нужен `pip install onnxruntime`.
- GigaAM падал «window shape cannot be larger…» на коротких обрывках — исправлено (`verify.segments`).
- «В папке лежат куски от другого запуска» — отпечаток `run.json` не совпал (другая книга/голос/разбор): удалить папку
  `--out` или указать другую. Проба `--questions` отпечаток не проверяет.
- Длины частей MP3 и кусков расходятся — часть mp3 осталась от прошлой озвучки (имена совпадают: `<книга>_частьNN.mp3`).
  Теперь `join` сам пересобирает часть, если она старее своих кусков; вручную: `--assemble`.
- Диск Google почти полон: удалять тестовые папки `bench*` и **очищать Корзину**.
- «Cannot mount drive» — разрешить сторонние cookie для colab.research.google.com, тот же аккаунт, Runtime → Disconnect
  and delete runtime, переподключить.
- Окончания слов: запас 60 мс в `tidy`, хвост текста при `--redo-weak` (не проверено на слух).
- OmniVoice больше не используется; не возвращаться без причины.

## 7. Не проверено / открытые вопросы

- Скорость F5 на Mac M1 (замер: `bench.py … --engine f5` с `PYTORCH_ENABLE_MPS_FALLBACK=1`).
- Помогает ли `--redo-weak` с хвостом против обрезанных окончаний; как звучат новые фразы для мест Библии.
- Список имён с ударением «+» для `fixes.txt` (имена иврит/библейские — главная слабость Silero).
- Заголовки и оглавление читает тот же голос с эффектом телефона — владелец не подтвердил окончательно.
- Страница для Mac не проверена в браузере глазами и на настоящей озвучке.

## 8. Правила работы с владельцем

Отвечать по-русски и коротко (сделано / изменено / не решено; неудобное первым). Новую функцию сначала план и согласие, потом
код. Не называть результат хорошим без прослушивания. Не публиковать чужие голоса: клонировать только голос владельца (или
с согласием). Пароли и ключи не просить и не хранить. Коммиты — на `main` с подписью, без PR, пока владелец не попросит.
