## 2026-10-06 — первый запуск на M1 и правка пауз

Проверено владельцем на «Два Вавилона» (2543 куска): модель OmniVoice работает,
~40 с на кусок при 32 шагах (≈28 часов на книгу). `duration_s` в mlx-audio —
целевая длина, а не максимум (в исходниках: target_len = ceil(duration_s * 25)),
поэтому кусок 0 имел 4.5 с тишины в конце. Теперь при склейке тишина по краям
обрезается, паузы > 0.8 с сокращаются до 0.5 с (проверено на 3 присланных кусках:
85.3 с -> 78.6 с, все паузы ≤ 0.6 с). Добавлены --limit и --out.
Не проверено: как звучит русский голос (оценка владельца), выигрыш по времени при --steps 16.

## 2026-10-06 — один голос на всю книгу (--voices, --ref)

Владелец оценил звук OmniVoice: «отлично». Обнаружено по высоте тона присланных
кусков (109, 190, 156 Гц): без образца модель берёт случайный голос для каждого куска.
Добавлено --voices N (N голосов читают одну фразу, рядом лежит voice_NN.txt с её текстом)
и автоподхват ref_text из соседнего .txt. Проверено на подставной модели.
Не проверено на настоящей: клонирование требует torch + torchaudio (поставлены в setup.sh),
скорость куска с образцом, схожесть голоса от куска к куску.
