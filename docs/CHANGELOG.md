## 2026-10-06 — первый запуск на M1 и правка пауз

Проверено владельцем на «Два Вавилона» (2543 куска): модель OmniVoice работает,
~40 с на кусок при 32 шагах (≈28 часов на книгу). `duration_s` в mlx-audio —
целевая длина, а не максимум (в исходниках: target_len = ceil(duration_s * 25)),

обрезается, паузы > 0.8 с сокращаются до 0.5 с (проверено на 3 присланных кусках:
85.3 с -> 78.6 с, все паузы ≤ 0.6 с). Добавлены --limit и --out.

## 2026-10-06 — полный аудит текста: local/ru_text.py

Аудит «Двух Вавилонов» (2741 кусок): цифры в 357 кусках (186 ссылок на стихи «Откр. 17:5», 31 диапазон,
29 годов), римские цифры 83 («Часть II», «Лев XII»), сокращения («т. е.» 119, «Рис.» 54, «прим.» 38),
латиница в 182 кусках (термины Pontifex Maximus и т. п., ссылки на авторов), слэш 72, квадратные скобки.
ru_text.normalize(): сокращения -> слова, римские цифры с родом и падежом (по существительному/имени),
годы порядковыми по предлогу («в 1853 году» -> «в тысяча восемьсот пятьдесят третьем году»), даты,
ссылки на стихи («глава семнадцать, стих пять»), остальные числа словами, слэш -> «или», латинские термины
транслитерируются списком, прочая латиница вырезается, кусок без русских букв -> тишина.
После правил цифр и латиницы в тексте для модели нет. Изменится 1076 кусков (≈ 1.1 ч переозвучки на T4).
Тесты: python3 -m unittest tests/test_ru_text.py. Не проверено на слух; падежи кардинальных чисел
(«25 городах») остаются именительными.
