# Поправки произношения. Формат: слово = как его записать для озвучки. Регистр важен: Веды и веды — разные записи.
# Куски с исправленными словами переозвучиваются командой с --redo-changed.
# Рабочий файл называется fixes.txt и лежит рядом с книгой (на Диске: Audiobook/fixes.txt).
#
# Опечатка в книге: «становиться очевидно» вместо «становится», из-за неё ударение читается неверно
становиться очевидно = становится очевидно
# Еврейские корни из одних согласных: переводчик книги сам пишет транскрипцию с «э» (Хэр-мэс, Кхэм, Мэлкэрт),
# так же допишем гласную здесь
рхм = рэхэм
Рхм = Рэхэм
мс = мэс
Мс = Мэс
Шнг = Шэнэг
млц = мэлэц
ркх = рэкх
кхмн = кхэмэн
# Ударения редких слов проверяются на слух; рабочая запись выбирается тестом (пример, не включён):
# велик = велИк
